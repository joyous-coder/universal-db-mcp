**Goal:** Add full SQLCipher coverage (templates + history), profile YAML import/export, key rotation, and history FTS5 full-text search — closing four deferred items from v2.16-v2.19 specs.

**Architecture:** Reuse v2.19's `EncryptedSqliteBackend`/`detectEncryptedBackend` to add cipher support to `TemplateStore` and `HistoryStore`. New `KeyRotator` orchestrates single-DB atomic rotation via temp-file + `rename()`. **Tech Stack:** TypeScript (ESM), vitest, existing `better-sqlite3-multiple-ciphers` optional dep, SQLite FTS5 (built-in via the same backend), zero new required npm deps, zero yaml libs (hand-rolled minimal YAML v1.2 subset parser).
