# v3.1 Index Advisor + Plan Diff + Plan History Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close out the long-deferred index-advice and plan-diff capabilities from v2.17/v2.19/v3.0 specs, with a separate `plan_history.db` snapshot store.

**Architecture:** New `ExplainPlanParser` normalizes EXPLAIN output across 17 adapters (4 native: sqlite/mysql/pg/mongodb; 11 raw passthrough; 2 unsupported). `IndexAdvisor` runs 4 heuristic rules against the normalized plan; `PlanDiff` does structural comparison; `PlanHistory` persists snapshots to a separate `plan_history.db` (introduced in v3.1, separate from `query_history.db`). MCP `explain_query_with_advice` + `compare_query_plans` + `list_query_plans` tools + 2 HTTP endpoints.

**Tech Stack:** TypeScript (ESM), vitest, SQLite's multi-backend (v2.16), better-sqlite3 (v2.16). Zero new required npm deps.

## Global Constraints

- All 450 v3.0 tests must continue to pass.
