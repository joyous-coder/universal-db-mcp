> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Revision history:**
>
> - v4 (9eb2ce1): Initial subagent-delegation approach with 17 DB L1 + 43 tool L2
> - **v5 (current)**: Pivoted to **direct native MCP exercise** + **43 independent per-tool todos** + **7 DB representative set** + **full env var matrix** + **per-tool 5-step lifecycle** + **restart on env/config change**

**Goal:** End-to-end test 7 representative DBs × all 43 MCP tools × all 7 env vars; capture every cell in a single report matrix; find/fix bugs; release v3.2.4.

**Architecture:**

- Current Claude Code session drives every MCP tool call (mcp__universal_db_mcp__*)
- WSL2 docker hosts one DB at a time, container `--restart=always` (no `--rm`)
- 14 sessions: S1-S7 per DB, S8-S14 per env var
- 43 independent per-tool todos (one tool per todo, tested across all 7 DBs)
- `mmx search` discovers Docker Hub configs (use `--region cn` for domestic DBs)

**Tech Stack:** TypeScript / Node 20+ / MCP stdio JSON-RPC / WSL2 docker / `mmx-cli` (web search)

## Global Constraints

- **One DB container at a time** — memory-constrained host
- **Container must use `--restart=always` + NO `--rm`** — container death = connection loss mid-test
- **All MCP calls go through `mcp__universal_db_mcp__*`** — never bypass with raw stdio (must test real user experience)
- **WSL only for docker**, not for Node/npm
- **Per-tool test = INSERT → UPDATE → SELECT → DELETE → SELECT** (data lifecycle)
- **No silent gaps** — every matrix cell marked ✅/❌/⚠️/skip/INFRA with note if non-✅
- **Bug severity**: 🔴 CRITICAL stops session (fix + restart), 🟡 MAJOR fixed in session tail, 🟢 MINOR logged + deferred
- **Commit prefix**: `feat:` / `fix:` / `test:` / `docs:` / `chore:` (Conventional Commits)
- **No untracked files at commit time** (per CLAUDE.md)

## Appendix A: Bug triage decision matrix (reference)

| Symptom                                                 | Severity                                        | Action                                                  |
| ------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------- |
| MCP server crashes (process dies, tool list disappears) | 🔴 CRITICAL                                     | Stop, restart Claude Code, debug, fix before continuing |
| Tool returns wrong data silently                        | 🔴 CRITICAL                                     | Fix immediately, regress                                |
| Tool returns clear error for invalid input              | ✅ (correct behavior)                           | No bug                                                  |
| Tool errors on valid input but works after retry        | 🟡 MAJOR                                        | Log, continue, fix in tail                              |
| Tool missing from`tools/list` after activation        | 🟡 (Bug#8 if Claude Code; OK if not registered) | Document, workaround                                    |
| Tool returns JSON with extra fields not in schema       | 🟢 MINOR                                        | Log, defer                                              |

## Appendix B: Restart protocol (reference)

Triggers:

1. **Env var change** — edit `.mcp.json`, kill MCP server, restart Claude Code
2. **MCP server crash** (Bug #7) — full Claude Code restart
3. **DB switch** (recommended for clean state) — restart

User prompt: "请重启 Claude Code 让 MCP server 重新加载 .mcp.json. 重启后回复 '重启了'."

After restart, verify: `mcp__universal_db_mcp__get_connection_status()` → expect not-connected, then call `connect_database` for active DB.
